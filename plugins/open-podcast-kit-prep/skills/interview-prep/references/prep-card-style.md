# 手卡措辞标准

这份标准来自一档职业访谈播客几十轮"AI 出稿 → 主持人手改"的真实返工记录：凡是主持人反复改的地方，都收成了一条规则。起草时就做到，别留给主持人返工。

## 一、起草洁癖（出稿即达标）

1. 编号连续干净，不留 `0.`、重复题号、空行等草稿痕迹。
2. 不加装饰性引号（"练兵场"→ 练兵场），用句号断句，少用破折号。
3. 去行业黑话、去重复语。题面是给嘉宾和听众听的，不是给同行看的。
4. 门槛别写太窄（"招一个博士"→"招一个硕士/博士"）。
5. 自我介绍题后面直接挂两个追问："能不能大概解释一下这个行业到底做什么"＋"用一句大白话解释你现在具体做什么"，不另起主线题。
6. 张力题、情绪题结尾加一句情绪探针（"现在回头看是什么心情？会觉得可惜吗？"）。
7. 一题最多两个问号（上限可在节目档案里改）。铺垫最多两句；写出三四连问时，把多出的问号拆成缩进的追问。主持人念 60 秒的长题，嘉宾只记得住最后一个问号——第二个问号只用来补一句短追问，别塞第二个独立问题。

## 二、富问题标准（最重要）

主持人最常见的抱怨是 AI 出的题"太干巴巴"。每道主线题先写平实版，再自问"这题能叠哪 2-3 层让它有张力"：

1. **把简历里最硬的数字和事实织进题面**："你在上一家公司做的会员体系，三个月把复购率拉高了 40%……"。数字越具体，越显得主持人做过功课，嘉宾也越难糊弄过去。
2. **摆一个挑衅或反常识的前提**："外界总说这行靠熬夜堆时间，从你带过团队的角度看是真的吗"。
3. **加情绪探针**（张力题必加）：不止问发生了什么，还要问当时什么感受——"有没有过想放弃的时候"。
4. **从听众好奇心切入**：点明这题替谁问——"对还在读书、想进这行的人来说，最好奇的可能是……"。
5. **先破再问**：先说大众的误解，再请嘉宾拆——"很多人以为产品经理每天就是画原型，但你其实……"。

**红线**
- 富不等于堆砌：一题最多叠两三层，别写成嘉宾读不完的小作文。
- 挑衅前提必须基于真实矛盾，AI 别硬造冲突。
- 织进去的数字必须准确，宁可不写也别写错。

**题面富，但只问一件事。** 背景可以多给，问号指向的必须是同一个问题（与第五节的"一题一动词"不矛盾：叠层是铺垫，动词只有一个）。

破冰自我介绍、黑话解释题保持平实即可；张力题、行业揭秘题、AI 与未来题最该叠满。

## 三、录前消息（一条消息，直接复制发送）

写成口语化的一段话，主持人不用改就能发。不编号、不硬换行，直接问、给默认值让对方确认；不写解释规矩或过度客套的话。

**七个固定要素（缺一即不合格）**

1. **形式告知**：视频播客要说清会录画面、正片发在哪些平台。
2. **着装与降压**：说明着装没有要求，可以加一句主持人自己的降压铺垫（例：「我那天会穿正装，纯属个人习惯，别有压力」）。
3. **称呼**：问对方希望在节目里被叫什么、字幕和封面用中文名还是英文名，并给一个默认值让对方确认。
4. **薪酬颗粒度给三档选项**：具体数字区间 / 只聊结构和大概水平 / 完全不聊。别写开放式的"方便聊到什么程度"。
5. **雷区单列**，并说"我提前避开"（别和薪酬揉成一条）。
6. **要一张清晰的正面照**做封面。
7. **挑题口径**：题很多都是可选的，挑最有表达欲、有故事讲的打勾，不想聊的都删掉；扫一眼有个印象就行，千万别提前准备答案。

另加：本期嘉宾专属、简历上看不出、需要提前确认口径的事，一事一行（例：「之前那个项目，节目里能讲到什么程度？」「这几家雇主能直接点名吗？」）。

模版（按节目档案替换）：

```
{称呼}你好！先跟你确认一下：这是个视频播客，会录画面，正片会发在{平台}。着装没任何要求，穿自己舒服的就行。

另外想跟你核实几个小事：
节目里你希望被叫什么？字幕和封面用中文名还是英文名？我默认是{默认称呼}，可以吗？
聊到薪酬方便公开到什么颗粒度？具体数字区间 / 只聊结构和大概水平 / 完全不聊，都 OK。
有没有你不想在节目里聊的雷区？我提前避开。
{本期专属口径，一事一行}

方便的话发我一张清晰的正面照，做节目封面用～

附上这次访谈的提纲，有很多可选题，挑你最有表达欲、有故事讲的打个勾就行，不想聊的我都可以删掉。扫一眼有个印象就行，千万别提前准备答案，主打一个自然～
```

**不进消息**：嘉宾上场要求（声音有起伏、回答简洁、靠近麦克风）——现场能解决的事不进录前消息。

## 四、有效形态、排序与衔接

### 有效问题的五种形态（每道主线题至少属于其一）

1. **行业硬信息**：薪酬档位、时间线、公司对比、典型一天——答案要可比较、可转述、有单位。
2. **挑衅前提张力题**：基于真实矛盾，题面本身就是钩子标题。
3. **翻译时刻 / 大白话解释**：前 15 分钟的理解地基，必须前置。
4. **场景化痛点 / 情绪探针**：必须长在具体场景上（"第一次约陌生前辈喝咖啡会紧张吗"有效，"怎么管理压力"裸问无效）。
5. **有前提的 AI 题**：先给出这个行业被 AI 改变的具体事实，再问判断。

**反差转折故事题**是第六种：它不产切片，产的是正片开头的吸引力和前 10 分钟留存。保留，讲完就走不恋战。

### 段间衔接：每段的出口答案天然指向下一段

- 一天流水账（出口：辛苦）→"这么辛苦，回报是什么"→ 薪酬
- 薪酬（出口：钱这么多）→"凭什么值这么多"→ 价值 / 张力题
- 行业揭秘（出口：真实门槛）→"那想进来的人怎么进"→ 求职时间线
- 为什么是你（出口：核心能力）→"这些能力 AI 替代得了吗"→ AI 题
- 未来规划（出口：人生选择）→"回头看"→ 收尾长谈

### 题间衔接：相邻两题至少占一种桥

1. **实体桥**：共享一个具体实体（同一家公司、项目、数字、人物）。
2. **反转桥**：上题正面、下题反面（最喜欢 → 槽点；光环 → 崩溃；外界以为 → 实际是）。
3. **词桥**：题面写成开放头，留给主持人现场接"你刚才提到 X……"。

### 节奏

- 硬信息题连续不超过 3 题，之后插一个情绪或场景题当呼吸口。
- 新信息不进最后 15 分钟；最后一段是情绪回报区，不是信息区。

## 五、交稿前自查（第一版交给主持人之前必须跑完）

### 硬性检查（不合格必须改完）

按 SKILL.md 的「交稿前自查」逐条核对。

### 内容清单（逐条自问）

1. 段间出口桥都对上了吗？
2. 相邻两题至少有一种桥吗？
3. 每段硬信息连续不超过 3 题吗？
4. 最后一段有没有塞新信息？挖新事实的题一律上移。
5. 条件题保留还是删掉，都在速览里写一句为什么。
6. 内部战术信息（短视频时刻、逼具体、装傻、翻译时刻、呼吸口、桥）只在速览区，一个都不进提纲。
7. 每个主问题都在速览区预写了一句"回拉句"吗（嘉宾跑题时用它拉回）？

跑完把结果写进手卡文末的「修订记录」，主持人一眼能看出每条落在哪。

## 六、主持习惯（每次出手卡都按这三条自检）

1. **一题一动词**：不要在同一句里同时问立场、案例、影响、行业结论。
2. **每个主问题预写一句回拉句**：嘉宾换题时用它拉回。例：问"典型一天"，嘉宾答成了商业模式，就用"能不能按昨天的时间线从早到晚说一遍"拉回来。
3. **每个职业排满六格**：职责 / 进入路径 / 薪资回报 / 核心能力 / 真实代价 / 适合与不适合。缺格现场补问。

听众代言三问必须闭环：**我怎么进去 / 我会赚多少 / 哪些人不要来**。
