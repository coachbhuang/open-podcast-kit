# 职业访谈题库（五段结构，约 90 分钟）

为具体嘉宾出手卡时，从这里删改、个性化，不要从零重写。
标"条件题"的只在嘉宾画像匹配时保留，不匹配直接删，并在速览里写一句为什么。
起草与排序标准见 `skills/interview-prep/references/prep-card-style.md`。

## #1 破冰 / 入行选择 / 日常
- 自我介绍（教育背景 + 之前的经历）
- 反差感：本科背景 vs 大家以为你会走的路 vs 实际走的路，转折点是什么
- 选择这个行业背后的自我探索故事 + 用一句大白话解释这个行业到底做什么
- 一天的流水账（从起床到睡觉）+ 工作与生活的平衡
- 在国内还是海外发展的思考（条件题：有跨地区经历的嘉宾）

## #2 行业与公司的个人见解
- 新人薪酬结构 / 奖金 / 福利 / 晋升速度（放在本段最前面）
- 外界对这个行业最大的误解
- 入行时没想到的挑战 + 什么时候觉得"适应了"（可选）
- 顶尖从业者最重要的 3 个特质 + 什么样的人不适合这一行（可选）
- 行业头部几家公司对比（文化、新人培养、薪酬、强度、面试流程，任选）
- 工作里最喜欢的部分 / 最大的槽点
- 印象最深的工作故事（优先用点名简历具体事件的版本；全开放版降为可选——嘉宾现场回忆成本高，答案质量随机）
- 对这个行业想吐槽的现象（吐槽行业，不吐槽具体同事）
- 一个关于这个行业的小众观点（条件题：嘉宾在简历或公开发言里显得很有主见才问）
- 不同地区职场文化差异（条件题：在两种职场文化里都工作过的嘉宾）

## #3 求职与生存法则
- 怎么拿到第一份实习 / 全职 offer + 30 秒讲清这一行的招聘时间线
- 印象最深 / 最难 / 最意外的面试题
- 求职资源推荐
- 求职建议
- 高强度下的压力管理（必须长在具体场景上问）
- 从老板或同事那里得到过的最有价值的建议（默认降为可选，或改成点名简历具体事件的版本）
- 是否被同辈压力或完美主义绑架过；怎么区分真热爱和维持光环的惯性

## #4 时代预判与下一步
- 未来职业规划
- 行业前景：AI 正在怎么改变它 + 雇主会更看重什么特质
- 这一行的退出通道（之后通常去哪）
- 为什么在这个时间点做出最近一次重大选择（读书 / 转行 / 创业等，按嘉宾经历改写）

## #5 给听众的建议（开放式长谈，情绪回报区，不塞新信息）
- 如果带着现在的认知回到大三 / 大四，会改变什么
- 平行宇宙：如果不在这个行业，会在哪里做什么（可选，快问快答）
- 给年轻 5–10 岁的人的建议：如何找到热爱并与职业规划平衡
- 高中生入行路线图：本科选什么专业、大学四年最该做哪三件事（条件题：一条路走到底的单行业深耕型嘉宾）
- 如何定义工作 / 生活的意义；回头看是否觉得充实（可选；适合做结尾）

## 附：90 分钟节奏母版

段内按"必问 → 高价值 → 可选"排，时间不够从段尾砍。

```
0-2    开场白 + 自我介绍（一行 + 两个追问）
2-10   反差转折故事（正片开头的吸引力来源；讲完就走不恋战）
10-16  翻译时刻（这行是什么、怎么赚钱——必须前置，是后面的理解地基）
16-24  一天流水账 + 工作生活平衡
24-32  薪酬 / 晋升硬信息（第一个硬信息高潮）
32-48  行业揭秘：先破再问误解 → 张力题 → 简历硬数字案例深挖 → 公司对比
48-62  求职战术：时间线 → offer 怎么拿 → 为什么是你 → 场景化压力（呼吸口）
62-75  AI 题（有前提）→ 退出通道 → 下一步选择
75-88  收尾：开放长谈（回到大三大四 / 给年轻人建议）
88-90  意义题 → 结尾落点
```
