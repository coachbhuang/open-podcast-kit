# 成片审片

剪辑的人自己验收容易"熟到麻木"，机器对内容没有感情，恰好能兜住人眼最容易漏的东西：坏帧、字幕缺失、超长死寂、响度不达标、字幕乱序。

**诚实说明局限**：Claude 不能像人一样连续看视频，只能全量处理音频信号 + 抽帧看图。跳剪是否自然、节奏好不好这类体验问题只能抽检，要在报告里明说。

## 流程

1. 跑脚本（长片几分钟到十几分钟，建议放后台）：
   ```bash
   python3 "<本 skill 目录>/scripts/review_cut.py" 成片.mp4 --sheets-out ./qc --cut-sheets
   ```
   同目录同名的 `.srt` 会自动带上检查；字幕在别处就用 `--srt` 指定。期望的分辨率、帧率填在 `kit.toml` 的 `[review]`。
2. 读 JSON 报告。`hard_failures` 里的是硬伤：
   - **字幕乱序**：重新导出字幕，或按开始时间重排。
   - **响度不达标**：转 `normalize-loudness` 的 fix。
   - **规格不符**：重新导出。
3. **长静音**（`long_silences`）逐条判断是刻意留白还是漏剪：对照字幕或转写稿看前后在说什么，判断和理由写进报告。
4. **逐张看网格大图**（`grid_sheets`，每张 5×5、30 秒一帧，按顺序从片头到片尾）：找黑屏、花屏、字幕缺失、构图跑偏、不该出现的画面（桌面、剪辑软件界面）、忘剪的废段。
5. **逐张看剪辑点大图**（`cut_sheets`，每个剪辑点后 0.25 秒一帧，对应字幕在 `cuts_index.json`）：判据只有一句——**这一帧里在说话的人，和这句字幕对得上吗**；再看相邻格子之间桌上的物件位置有没有突变，突变说明素材来自别的时刻。30 秒网格会漏掉比它短的错误片段，这一步就是为它补的。
6. 出报告：硬伤 / 需要人判断的疑点（带时间点）/ 已检查无问题的项 / 机器查不了的部分。时间点写成 `时:分:秒`。
