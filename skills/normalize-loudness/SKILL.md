# 响度检查与校正

很多剪辑软件导出时不做响度归一，成片常常只有 -20 到 -24 LUFS，比平台参考线安静 6-10 dB，观众的感受就是"这期声音好小"。修它不需要重剪，也不需要重压视频，只处理音轨。

脚本：本 skill 目录下的 `scripts/loudness.py`，只依赖 ffmpeg / ffprobe。目标值在 `kit.toml` 的 `[loudness]` 里。

## 默认目标

| 交付物 | 目标 | 真峰值底线 |
|---|---|---|
| 视频（mp4 / mov 等） | -14 LUFS | 不高于 -1.0 dBTP |
| 纯音频（mp3 / m4a 等） | -16 LUFS | 不高于 -1.0 dBTP |

与目标差 1 LU 以内就算达标，不要过度处理。同一期的视频和音频目标不同，**音频版不能直接抽视频的音轨了事**，要单独测、单独校正。

## 流程

1. **先测**（可一次测多个文件）：
   ```bash
   python3 "<本 skill 目录>/scripts/loudness.py" measure 成片.mp4 成片.mp3
   ```
   verdict 为 OK 就到此为止，把数值报给用户。报告里还有噪底（noise_floor_dbfs）和信噪比（snr_db）：测不出时会明说原因，**绝不硬给数字**——剪掉了停顿的成片天然测不出，要拿未剪的原始录音重测。
2. **不达标再修**（每个文件各跑一次，不覆盖原文件，输出 `_loudnorm` 后缀）：
   ```bash
   python3 "<本 skill 目录>/scripts/loudness.py" fix 成片.mp4
   ```
   做法固定是"固定增益 + 限制器"，不用动态音量自动调节——后者会让人声忽大忽小。修完脚本会复测，响度和真峰值都过了才输出 `verified: true`。
3. **拼接型成片再分段测**：冷开场 + 正片 + 片尾这类由多段拼起来的成片，整片达标不代表合格（常见是片尾音乐比正片小 8 LU）。
   ```bash
   python3 "<本 skill 目录>/scripts/loudness.py" segments 成片.mp4 --bounds 45,3540
   ```
   `--bounds` 填真实拼接点（秒）；不给就按 5 段等分粗筛。任意两段差超过 2 LU 就不合格，要回剪辑软件把那一段单独调平再导出——整片归一化拉不平段间差。

## 边界

- 录音本身的大小声（人离麦克风时远时近）不是归一化能修的，要在录音端或剪辑时按说话人调轨。本工具保留原本的轻重关系，只削尖峰。
- 降噪不在本工具里做。
