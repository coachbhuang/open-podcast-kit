# 嘉宾邀约

先读节目档案 `kit.toml`（节目名、受众、访谈时长、嘉宾权益、是否视频播客）。

## 首次邀约

按对方习惯的语言和渠道（微信、领英、邮件）写，包含：

1. **一句话节目定位 + 为什么是 Ta**：点名 Ta 经历里的反差点或独特之处，让对方知道你做过功课。
2. **嘉宾权益**：用 `kit.toml` 里的 `guest_benefits`，不夸大。
3. **时间成本透明**：访谈约多少分钟、题目会提前给、在哪录（线下或远程）。视频播客要说清会录画面。
4. **一个具体的时间提议**（周几 + 时段，写明时区），降低对方回复的成本。

短，口语化，一屏读完。

## 跟进节奏（对方没回时）

- 第 4 天：轻提醒，换个由头（比如附上节目最新一期的链接）。
- 第 10 天：最后一次，给台阶（"最近忙的话放到下个月也完全可以"）。
- 之后归档到"以后再约"，不再打扰。

## 对方答应之后

转 `interview-prep`：录前消息和题单 PDF 都由它出。

## 跟进表

在用户工作目录维护 `guests/outreach-log.md`，每位候选嘉宾一行：姓名 / 行业 / 状态（待邀约 → 已发出 → 已回复 → 已确认 → 已录制）/ 最后动作日期 / 下一步。每次用本 skill 时先读表，主动提醒到期该跟进的人，写完消息再更新表。

## 红线

- 不过度承诺流量或商业效果。
- 你只出终稿，发送动作永远由用户本人完成。
