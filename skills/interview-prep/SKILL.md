# 访谈准备

## 开工前先读

1. 节目档案 `kit.toml`（在用户工作目录或其上级；没有就用本仓库根目录的 `kit.example.toml`，并提醒用户复制一份改成自己的节目信息）。
2. 题库：`kit.toml` 里 `[prep].question_bank` 指定的文件；没指定就用本仓库 `presets/<format>/question-bank.md`。
3. 本 skill 的 `references/prep-card-style.md`（措辞标准，起草每道题前必读）和 `references/card-template.md`（章节结构）。

## 输入：先自查，查不到再问

嘉宾姓名、行业、公司、教育背景、职业路径亮点，先从用户给的简历（PDF / 文字）和对话里取。能联网就主动搜嘉宾的公开信息（领英、公司页、采访文章）补全，搜不到就用用户给的信息，**绝不编造**。

发现嘉宾上过其他播客或视频访谈，用 `guest-research` skill 拉逐字稿：摸清 Ta 讲过哪些故事、哪些角度已经被问烂。

嘉宾资料一律放在用户自己的工作目录 `guests/<姓名>/` 下（本仓库 `.gitignore` 已排除），文件用姓名命名，不用集号——播出顺序会变。

## 产出：`guests/<姓名>/prep_v1.md`

按 `references/card-template.md` 的结构写。要点：

- **每段 8-10 道主线题备选**（数量见 `kit.toml`），宁多勿少——最终问哪几题由主持人挑。
- 题库里的通用题改写成点名 Ta 经历的具体问法；不适用的题删掉。
- 每道题先写平实版，再按 prep-card-style §二 叠 2-3 层（简历硬数字 / 挑衅前提 / 情绪探针 / 听众视角 / 先破再问）。
- **提纲区会被原样发给嘉宾**：零战术标注，提到嘉宾一律用"你"。战术信息（短视频时刻、逼具体、装傻追问、翻译时刻、回拉句）全部写在嘉宾速览区。
- 开场白套 `kit.toml` 里的模板，"今天，我们……"一句给 5 个备选。
- 文末必带「题目角度标签」节：每道主线题一行 `- **#1.2**：入行路径｜在校生`，角度和视角从 `kit.toml` 的清单里选。

## 交稿前必须跑完自查

```bash
python3 "<本 skill 目录>/scripts/check_prep_card.py" "guests/<姓名>/prep_v1.md"
```

FAIL 必须清零；再逐条过 prep-card-style §五 的人工清单，把结果写进手卡文末的修订记录。

## 主持人改稿

手卡是活文档：主持人要改时，基于现有文件出下一版（`prep_v2.md`……），不要重新生成，旧版本不覆盖。**宁降可选不删题**：主持人没明说删的题，改成 `〔可选〕` 前缀保留。

**别让主持人在文本编辑器里啃 markdown**，给他起网页版编辑器：

```bash
python3 "<本 skill 目录>/scripts/prep_card_serve.py" --open
```

不带参数打开嘉宾列表；也可以直接给嘉宾名或手卡文件路径。嘉宾目录默认是 `kit.toml` 所在目录下的 `guests/`，可用 `--guests` 指定。页面上每道题都能删掉、降为可选、改写、加批注、加追问、在任意位置插新题、上移下移（可跨段）；其余章节点哪段改哪段。保存永远写成下一个版本号的新文件，删掉的题进文末备查区，批注汇总到文末内部区不进提纲，题号与角度标签自动跟着重排，存完自动跑一遍手卡自查并把结果显示在页面上。编辑器只监听本机，只读写嘉宾目录里的 `prep_vN.md`。

## 发给嘉宾的题单 PDF

```bash
python3 "<本 skill 目录>/scripts/prep_outline_pdf.py" "guests/<姓名>/prep_vN.md" --guest "<称呼>" --sections "入行与日常,行业见解,求职与生存,未来与下一步,给听众的建议"
```

只取分段提纲那一节，速览和内部备注物理上进不去。`--sections` 用给嘉宾看的段名（手卡里的段标题可能带内部说法）。没装 Playwright 时输出 HTML，浏览器打印成 PDF 即可。

主持人把「录前消息」和题单 PDF 一起发给嘉宾，嘉宾勾选想聊的题。

## 定稿（录制前几天）

按嘉宾勾选收敛成定稿手卡，**每题改写成主持人可以直接照念的完整口语问句**。嘉宾没勾的题不删，按三色标优先级：

- 🟢 `〔嘉宾想聊〕`：嘉宾勾过的题，第一优先；
- 🟠 `〔必问·未勾〕`：嘉宾没勾、主持人标必问的题，第二优先；
- ⚪ `〔可选·未勾〕`：嘉宾没勾、主持人标可选的题，第三优先。

嘉宾在回复里给的口径（称呼、薪酬颗粒度、不点名的公司）落进题面和速览里的"现场红线"。

## 原则

- 主持人人设默认是"对这个行业一无所知的好奇学生"：嘉宾说黑话就当场追问；黑话速查表是兜底，不是替代追问。
- **翻译时刻**：每期挑一个概念，请嘉宾"讲给一个高中生听"——降维输出，天然适合做短视频。
- **逼具体**：薪酬、强度、时间类回答模糊时，当场追问成可比较的单位（一周几小时、第一年到手多少）。
- 收尾题要具体到能被记住和转述，拒绝"多尝试、找到热爱"式的空话。
- 遵守 `kit.toml` 里的内容红线。
