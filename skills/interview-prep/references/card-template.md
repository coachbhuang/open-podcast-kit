# 手卡模版

章节顺序固定：嘉宾速览 → 行业黑话速查 → 开场白 → 分段提纲 → 录前消息 → 题目角度标签 → 修订记录。
开场白放在速览和黑话之后：主持人先看完嘉宾背景和行业术语，再定开场白。

**哪些会发给嘉宾**：只有「分段提纲」（题单 PDF 只取这一节）和「录前消息」。其余全是主持人自用，战术信息只许写在速览区。

```markdown
# {嘉宾称呼} 访谈手卡（{行业}）

## 嘉宾速览
- 履历链条：{本科 → … → 现在}，反差点在哪
- 简历里最硬的 3-5 个数字 / 事实（出题要织进题面）
- 已经上过的其他访谈讲过什么（避免重复问法）
- 战术备注：必抓的短视频时刻 / 逼具体点 / 装傻追问点 / 翻译时刻 / 每个主问题的回拉句
- 条件题取舍及理由

## 行业黑话速查
| 词 | 大白话 |
|---|---|
| … | … |
（5-7 条，只留本期嘉宾最可能说出口、听众最可能卡住的词）

## 开场白
{kit.toml 里的开场白模板，{guest} 已替换}
- 备选1：今天，我们……
- 备选2：……
（"今天，我们……"一句给 5 个备选，主持人看完全卡再挑，别替他定）

## 分段提纲
### #1 {给嘉宾看的段名，不含内部词、不用第三人称}
1. {主线题}
　　*followup：* {追问}
　　*followup（可选）：* {可选追问}
2. 〔可选〕{可选主线题}
…
### #2 …

## 录前消息
{按 prep-card-style.md §三 的七要素模版写成一段}

## 题目角度标签（内部，不发嘉宾，按 v1 题号）
- **#1.1**：个人故事｜通用
- **#1.2**：入行路径｜在校生
…

## 修订记录
| 版本 | 改了什么 | 自查结果 |
|---|---|---|
| v1 | 初稿 | check_prep_card 0 FAIL；人工清单 7 条已过 |
```
