# 嘉宾调研

## 做什么

1. **公开资料**：能联网就搜嘉宾的领英、公司页、采访文章、公开演讲，记下：履历链条、简历里最硬的数字和事实、Ta 公开表达过的观点。只记查得到出处的，搜不到就写"未查到"，绝不编造。
2. **过往访谈逐字稿**：发现嘉宾上过播客或视频访谈，就把逐字稿拉下来，整理出：
   - Ta 已经讲过的故事（出题时换角度，别让听众听重复内容）；
   - 被问过很多次的问题（降为可选或换问法）；
   - Ta 讲得最兴奋、但别人没追问下去的点（最值得深挖）。
3. 结果写到用户工作目录 `guests/<姓名>/research.md`，交给 `interview-prep` 用。

## 拉逐字稿用的工具

推荐社区开源工具 [podcast-transcript-txt-skill](https://github.com/KingJing1/podcast-transcript-txt-skill)（MIT 许可，作者 @一龙小包子）：支持小宇宙单集页、Apple Podcasts、YouTube 和音频直链，优先用官方逐字稿或平台字幕，拿不到时用 faster-whisper 在本机转写，不需要任何 API 密钥。

本仓库不内置它的代码，第一次用时按它的 README 安装即可。装好后在嘉宾目录下运行它，把逐字稿输出到 `guests/<姓名>/research/`。

## 边界

- 不绕过登录、付费墙或版权保护。
- 自动转写是草稿：人名和术语容易错，引用进手卡前先校对。
- 嘉宾资料属于个人信息，只放在用户自己的工作目录，不要提交到任何公开仓库。
